# Chapter 6 source notes

The uploaded textbook extract confirms that the source chapter is **Chapter 6: Relativity**. Its learning-objectives page explicitly includes: the terms **reference frame** and **inertial reference frame**; Galilean relativity and transformation equations for position, time, and velocity; Einstein’s two postulates of special relativity; the way those postulates lead to Lorentz transformation equations for the same event viewed from two reference frames; Lorentz transformation for **relativistic velocity addition**; spacetime interval as an invariant quantity; **proper time interval** and **proper length**; time dilation and length contraction; relativistic simultaneity; spacetime diagrams (Minkowski diagrams); and muon decay as evidence for time dilation and length contraction.

The chapter’s guiding question is: **“What are the consequences of the constancy of the speed of light on our understanding of space and time?”**

The introduction states that the chapter treats the kinematic parts of Einstein’s 1905 special relativity, including length contraction, time dilation, the speed of light as the ultimate limiting speed for material objects, and pictorial representation of relativity through spacetime diagrams.

Section **6.1 Reference frames and Lorentz transformations** begins by defining a reference frame as a set of co-ordinate axes and a set of clocks at every point in space. It states that if the set is not accelerating, the frame is an **inertial reference frame**. The early worked context uses a lightning-strike event recorded by ground and train observers, then derives the Galilean relation **x′ = x − vt** and **t′ = t** before moving into relativity.

## Velocity-addition reference

The source’s **Addition of velocities** subsection states the reference-frame convention used for the challenge: S′ moves at constant speed **v** relative to S; the object speed measured in S′ is **u′**; and the object speed measured in S is **u**. The chapter contrasts the invalid Galilean relation **u = u′ + v** with the relativistic relation **u = (u′ + v) / (1 + u′v / c²)**. The inverse relation is **u′ = (u − v) / (1 − uv / c²)**.

The chapter’s rocket-and-missile example uses **v = 0.80c** and **u′ = 0.50c**, yielding **u ≈ 0.93c** rather than the impossible Galilean result 1.30c. Its light-beam example confirms that substituting **u′ = c** still yields **u = c**. These will become preloaded challenge scenarios.

## Effects and diagrams reference

The source defines a **proper time interval** as the time between two events that take place at the same point in space and presents time dilation as *time interval = γ × proper time interval*. It defines **proper length** as a length measured in the object’s rest frame and stresses that contraction applies only in the direction of motion. The muon-decay application uses a 2.2 μs rest-frame lifetime, a 3.0 km mountain, and a muon moving at 0.99c to connect time dilation and length contraction to experimental evidence.

Section **6.3 Spacetime diagrams** places time on the vertical axis and position on the horizontal axis, then uses **ct** vertically so both axes have length units. It explains that a photon traces a 45° worldline and that a material particle’s worldline always lies inside the light cone. The module’s existing Minkowski instrument already uses this convention and will now state it with the source terminology.
